# Asper Beauty: Audit Logs ("Medical History")

This folder holds **24-Hour Clinical Audit** reports and related diagnostics.
Each report is a snapshot of storefront health after go-live and at key
milestones.

**Purpose:** Create a "Medical History" for your storefront as you scale to
10,000+ SKUs or expand into the physical app. Reference past audits when
debugging or before a new launch wave.

**Target structure:**

- `docs/audits/README.md` — This protocol
- `docs/audits/24_HOUR_CLINICAL_AUDIT.md` — The template
- `docs/audits/YYYY-MM-DD_24h_audit.md` — Your first and subsequent reports
  (e.g. `2026-02-08_launch_audit.md`)

**How to use:**

1. **Template:** Copy [24_HOUR_CLINICAL_AUDIT.md](24_HOUR_CLINICAL_AUDIT.md) for
   each audit run.
2. **Naming:** Save completed reports as `YYYY-MM-DD_24h_audit.md` (e.g.
   `2026-02-08_launch_audit.md`).
3. **Location:** Keep all 24-hour and follow-up audit reports in this folder.
